# Criterios de evaluación · ZZZ) MRD

`ZZZ) MRD` es más estricto que `ZZZ) El Pozo`.

## Diferencia entre El Pozo y MRD

| Sección | Qué significa | Qué hacer |
|---|---|---|
| `ZZZ) El Pozo` | Pendiente, dudoso o sin clasificar | Puede revisarse con calma |
| `ZZZ) MRD` | Baja prioridad, freebie dudoso, shovelware, test build o descarte probable | No tocar salvo razón clara |

## Reglas para sacar algo de MRD

Un juego solo puede salir de MRD si pasa al menos una de estas pruebas:

1. **Prueba de interés:** de verdad dan ganas de jugarlo, no solo acomodarlo.
2. **Prueba de reputación:** tiene reseñas, comunidad o recomendación externa suficiente.
3. **Prueba social:** sirve para jugar con alguien o para una sesión meme concreta.
4. **Prueba de rareza útil:** aunque sea raro, aporta algo que no cubren otros juegos.
5. **Prueba rápida:** 10 a 20 minutos bastan para confirmar que no es basura.

## Reglas para no mover

No se mueve un juego de MRD solo porque:

- técnicamente sea puzzle, arcade, RPG, terror o plataformas;
- tenga cromos/logros;
- sea gratis;
- esté instalado por accidente;
- aparezca en una captura;
- tenga portada bonita.

## Resultado posible

| Resultado | Acción |
|---|---|
| Vale la pena | Mover a colección limpia o a El Pozo si aún hay duda |
| Curioso pero débil | Mantener en MRD |
| No aporta | Mantener en MRD o considerar ocultar/desinstalar |
| Es demo/prologue | Solo seguir si interesa el juego base |
| Es test server/build experimental | No tratar como juego principal |
