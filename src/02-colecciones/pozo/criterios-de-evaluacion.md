# Criterios de evaluación · El Pozo

## Objetivo

Evitar que `ZZZ) El Pozo` ensucie las colecciones buenas. El Pozo funciona como cuarentena, no como género.

## Veredictos

| Veredicto | Uso |
|---|---|
| ✅ Sí, candidato real | Juego que sí vale una prueba inicial o revisión manual. |
| 🟨 Quizá, revisar primero | Puede valer, pero no hay suficiente señal para priorizarlo. |
| 🧪 Solo curiosidad / baja prioridad | Freebie, rareza o juego menor. Probar solo por curiosidad. |
| 🟥 No priorizar | No conviene gastar tiempo salvo que alguien lo pida explícitamente. |

## Movimiento permitido

Un juego solo sale de El Pozo si se cumple una condición clara:

1. Se probó y gustó.
2. Alguien de la familia lo pidió.
3. Tiene valor social real.
4. Tiene reputación suficiente para subirlo a backlog.
5. Pertenece a una saga/universo que sí se quiere conservar.

## Movimiento no permitido

No mover por pura etiqueta técnica:

- “Es shooter, entonces va a Shooter”.
- “Tiene crafting, entonces va a Supervivencia/Crafting”.
- “Es online, entonces va a Internet persistente”.

Eso infla las colecciones y las vuelve menos útiles para decidir qué jugar.
