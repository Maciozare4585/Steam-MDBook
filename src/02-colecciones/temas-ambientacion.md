# 11. 🌌 Nivel 4 — Tema / ambientación

Actualmente existe como **nivel conceptual**, pero no hay colección temática activa.

| Tema candidato | Estado | Criterio |
|---|---|---|
| 🌌 Postapocalíptico | Candidato principal | Solo si se usa como antojo real |
| 🧟 Zombies | Opcional | Menos prioritario que Postapocalíptico |
| 🧱 Pixel Art | Estética candidata | Solo si se elige juego por estética visual |
| 🌃 Cyberpunk / Sci-fi distópico | Opcional | Crear si crece |
| 🐉 Fantasía oscura | Opcional | Se cruza con Souls/RPG |
| 🗾 Anime / Japón | Opcional | Alto riesgo de contaminar sagas limpias |

> **Regla:** una colección temática no debe volverse etiqueta exhaustiva.
