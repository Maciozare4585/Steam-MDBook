# 5. 🧠 Reglas de decisión

## 5.1. Regla rápida

| Si quiero... | Ir a... |
|---|---|
| Avance real | `1) SIN TERMINAR` |
| Cierre secundario | `2.5) POSTGAME / EXTRAS` |
| Algo seguro y conocido | `7) TOCA REPLAY` o `Favoritos` |
| Algo social | `YYY)` |
| Algo ligero | `Chill`, `Cozy`, `Arcade / Casual` |
| Algo intenso | `Souls`, `Terror`, `Shooter`, `Metroidvania` |
| Algo mental | `Puzzle`, `Táctico por turnos`, `Gestión` |
| Algo online | `Internet Persistente` |
| Algo nuevo | `3) LO QUIERO JUGAR (NUEVO)` |

## 5.2. Matriz de decisión

| Tengo... | Quiero... | Mejor opción |
|---|---|---|
| Poco tiempo | Algo con cierre rápido | Arcade / Casual, Roguelike, Puzzle corto |
| Mucho tiempo | Avance serio | Campaña, RPG, Sin terminar |
| Cansancio | Baja fricción | Chill / Relax, Cozy, Dave, Peggle |
| Energía | Reto | Souls, Hollow Knight, Cuphead |
| Amigos conectados | Social | YYY, HELLDIVERS 2, Lethal Company |
| Ganas de progreso | Build/grind | Monster Hunter, Warframe, Path of Exile |
| Curiosidad | Probar algo | 3) Nuevo o ZZZ con filtro |
| Nostalgia | Zona segura | Favoritos, Toca Replay |

## 5.3. Regla anti-LoL automático

Antes de abrir LoL por reflejo:

```text
1. ¿Quiero social?
   -> HELLDIVERS 2 / Yu-Gi-Oh! / YYY

2. ¿Quiero apagar el cerebro?
   -> Peggle / Dave / Infectonator / PvZ

3. ¿Quiero progreso real?
   -> RE4 / NieR / Monster Hunter / Elden Ring

4. ¿Quiero competitivo?
   -> LoL sí aplica, pero conscientemente.
```

## 5.4. Regla de cierre


> **Nota técnica:** si Steam llegara a dar problemas con el nombre `2.5) POSTGAME / EXTRAS` en algún cliente, la alternativa segura sería `🎁 POSTGAME / EXTRAS` o `2-5) POSTGAME / EXTRAS`. Si el nombre actual funciona, no hace falta cambiarlo.

| Estado | Pregunta |
|---|---|
| `1) SIN TERMINAR` | ¿Todavía quiero terminar la historia/base? |
| `2) TERMINADOS` | ¿Ya lo doy por cerrado? |
| `2.5) POSTGAME / EXTRAS` | ¿Ya cerré base, pero queda contenido importante? |
| `5) PA PLATINAR` | ¿Quiero 100%, logros o completado fuerte? |
| `7) TOCA REPLAY` | ¿Lo volvería a empezar o revisitar por gusto? |
| `8) ABANDONADO` | ¿Ya no quiero seguirlo por ahora? |
