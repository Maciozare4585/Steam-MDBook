# 13. 📌 Mini-guía de valores sugeridos

## 13.1. Energía requerida

| Valor | Cuándo usarlo |
|---|---|
| Baja | Puedo jugar cansado o distraído |
| Media | Requiere atención, pero no me drena |
| Alta | Requiere concentración, mecánica, historia o memoria |

## 13.2. Sesión ideal

| Valor | Uso |
|---|---|
| 10-30m | Casual, run corta, puzzle, arcade |
| 30-90m | Buen avance sin compromiso enorme |
| 1-2h | Campaña, acción, co-op, progreso serio |
| 2h+ | RPG, souls, táctico, historia densa |

## 13.3. Fácil de retomar

| Valor | Significado |
|---|---|
| Sí | Puedo abrirlo sin recordar mucho |
| Medio | Requiere reubicarme un poco |
| No | Si lo suelto mucho, me pierdo |

## 13.4. Riesgo de reinicio

| Valor | Significado |
|---|---|
| Bajo | Retomar es viable |
| Medio | Tal vez conviene repasar o calentar |
| Alto | Probablemente conviene reiniciar |

## 13.5. Prioridad

| Valor | Significado |
|---|---|
| Alta | Quiero jugarlo pronto o tiene peso fuerte |
| Media | Interesa, pero no urge |
| Baja | Está bien ubicado, pero no mueve aguja |
| Variable | Depende de amigos, evento, mood o temporada |
