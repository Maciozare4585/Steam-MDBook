# 14. ✅ Checklist antes de agregar algo nuevo

```markdown
- [ ] ¿Esto ayuda a decidir qué jugar?
- [ ] ¿No duplica información ya clara en el documento maestro?
- [ ] ¿No convierte el documento en una bitácora?
- [ ] ¿La sección se puede mantener sin flojera?
- [ ] ¿Tiene campos concretos y no puro relleno?
- [ ] ¿El juego realmente necesita ficha o basta con una fila compacta?
```
