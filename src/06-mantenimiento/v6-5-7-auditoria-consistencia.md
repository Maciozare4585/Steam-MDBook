# 🧾 V6.5.7 — Auditoría de consistencia

Esta página documenta la revisión posterior aplicada sobre la versión V6.5.7 revisada.

## Motivo

La versión anterior mezclaba contenido de ramas posteriores y tenía inconsistencias en colecciones visibles.

## Cambios aplicados

| Área | Corrección |
|---|---|
| Changelog histórico | Se retiraron entradas prematuras de versiones posteriores para mantener esta entrega dentro de la línea `V6.5.7`. |
| Assassin’s Creed | Se agregó `Assassin’s Creed II`; la colección pasa de 4 a 5 juegos. |
| Sagas / universos | Se reordenó la lista visible en orden alfabético. |
| Estrategia | Se retiraron `Battle for Wesnoth`, `Chroma Squad`, `Jagged Alliance Gold` y `Songs of Conquest`; la colección pasa de 23 a 19 juegos. |
| Gestión | Se retiró `Graveyard Keeper`; la colección pasa de 12 a 11 juegos. |
| Internet Persistente | Se agregaron `Delta Force`, `Natural Selection 2`, `STALCRAFT: X` y `The Mean Greens - Plastic Warfare`; la colección pasa de 55 a 59 juegos. |
| Backlog / ficha exprés | Se ordenó alfabéticamente la tabla de `3.4. Ficha exprés para backlog no estelar`. |
| Favoritos | Se ordenó alfabéticamente la tabla visible. |
| Metadatos | Se agregaron entradas mínimas de registry para `Natural Selection 2`, `STALCRAFT: X` y `The Mean Greens - Plastic Warfare`. |

## Regla de mantenimiento

Una versión empaquetada como `V6.5.7` no debe registrar cambios de versiones posteriores dentro de su changelog histórico, salvo que estén marcados explícitamente como pendientes futuros.
